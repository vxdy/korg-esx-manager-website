Funktionen

Alles, was eine .esx-Datei enthält, in einem Editor

Sechs Tabs decken den kompletten Inhalt einer Electribe-Projektdatei ab, dazu ein Datei-Explorer und ein Pattern-Browser zur Verwaltung deiner Bibliothek.

ⓘ

Info-Tab

Übersicht über Dateistatistiken: genutzte Patterns, Samples und Songs sowie belegter Sample-Speicher.

⚙

Global-Tab

Bearbeite die globalen Parameter der .esx-Datei direkt, ohne dich durch Gerätemenüs zu klicken.

▦

Patterns-Tab

Patterns anzeigen und bearbeiten. Einzelne Patterns inkl. referenzierter Samples als .esxpat exportieren oder importieren, um sie zwischen Projekten auszutauschen.

♪

Samples-Tab

WAV-Samples importieren, optional mit automatischer Mono-Konvertierung, Wellenform ansehen, per eingebautem Player vorhören und einzelne oder ungenutzte Samples löschen.

♫

Songs-Tab

Die in deiner Projektdatei gespeicherten Songs anzeigen und bearbeiten.

📁

Datei-Explorer & Pattern-Browser

Eine andockbare Seitenleiste zum Navigieren im Dateisystem und Öffnen von .esx-/.wav-/.mp3-/.aiff-Dateien, plus ein Browser zur Verwaltung exportierter Patterns.

Oberfläche

Ein dunkler, fokussierter Arbeitsbereich

Loslegen

Open Electribe Editor installieren

Für den Start aus dem Quellcode wird Python 3.11+ benötigt. Fertige Binaries gibt es aktuell nur für Windows.

1

Releases-Seite öffnen

Gehe zum Reiter Releases auf GitHub und lade die neueste OpenElectribeEditor.exe herunter.

2

Oder einen CI-Build laden

Alternativ: Actions → neuester erfolgreicher Lauf von Build Windows EXE → Artifact OpenElectribeEditor-windows-exe herunterladen (erfordert GitHub-Login).

3

Starten

Artifact bei Bedarf entpacken und OpenElectribeEditor.exe direkt starten — es ist keine Python-Installation nötig.

# Repository klonen
git clone https://github.com/vxdy/Open-Korg-ESX-Sample-Manager.git
cd Open-Korg-ESX-Sample-Manager

# Virtuelle Umgebung anlegen und aktivieren
python -m venv venv
venv\Scripts\activate

# Abhängigkeiten installieren
pip install -r requirements.txt

# Anwendung starten
python main.py
# Repository klonen
git clone https://github.com/vxdy/Open-Korg-ESX-Sample-Manager.git
cd Open-Korg-ESX-Sample-Manager

# Virtuelle Umgebung anlegen und aktivieren
python3 -m venv venv
source venv/bin/activate

# Abhängigkeiten installieren
pip install -r requirements.txt

# Anwendung starten
python3 main.py

# Falls sounddevice PortAudio nicht findet:
brew install portaudio
FAQ

Häufige Fragen

Was ist eine Korg-Electribe-.esx-Datei?

Die .esx-Datei ist das Projektformat der Korg-Electribe-Workstations. Sie enthält Patterns, Samples, Songs und globale Parameter. Open Electribe Editor liest und schreibt dieses Format auf deinem Computer, außerhalb des Geräts.

Ist Open Electribe Editor kostenlos und quelloffen?

Ja. Der vollständige Quellcode ist auf GitHub verfügbar, und fertige Windows-Builds werden kostenlos auf der Releases-Seite des Projekts veröffentlicht.

Welche Betriebssysteme werden unterstützt?

Windows und macOS sind getestet. Für Windows gibt es eine fertige .exe; auf macOS wird die App aus dem Quellcode mit Python gestartet. Unter Linux mit installiertem PyQt6 und PortAudio sollte es ebenfalls laufen, ist aber nicht offiziell getestet.

Muss ich Python installieren, um die App zu nutzen?

Unter Windows nicht, wenn du die fertige OpenElectribeEditor.exe von der Releases-Seite nutzt. Für den Start aus dem Quellcode unter Windows, macOS oder Linux wird Python 3.11 oder neuer benötigt.

Was ist eine .esxpat-Datei?

Das ist das Format, mit dem Open Electribe Editor ein einzelnes Pattern samt referenzierter Samples exportiert, um es zwischen .esx-Projekten auszutauschen.

Kann ich eigene WAV-Samples importieren?

Ja. Im Samples-Tab lassen sich WAV-Dateien importieren, optional mit automatischer Mono-Konvertierung, per eingebautem Player und Wellenform-Anzeige vorhören, und einzelne oder ungenutzte Samples löschen.

Sendet die App Daten über das Netzwerk?

Unter Help → Sende Debug Daten kannst du steuern, ob Debug-/Fehlerberichte an einen Debug-Server gesendet werden, um bei der Fehlersuche während der Entwicklung zu helfen. Das ist eine Einstellung, die du im Help-Menü selbst kontrollierst.

Bereit, deine Electribe-Bibliothek zu verwalten?

Lade den Windows-Build herunter oder klone den Quellcode auf GitHub — kostenlos.
